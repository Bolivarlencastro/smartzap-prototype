# Styling Conventions

- Component styles in SCSS (scoped)
- Tailwind CSS for layout utilities
- Angular Material with custom theme integration
- Shared SCSS variables/mixins from `libs/shared-ui/layout`
- Prettier: 120-char print width, single quotes, 2-space tabs, semicolons
- Do NOT use BEM naming conventions — Angular's scoped SCSS already handles encapsulation
- Do NOT use `::ng-deep` — use proper Angular component encapsulation or host selectors instead
