Smartzap Prototype

Visão geral do fluxo conversacional

Este conteúdo demonstra como o Smartzap pode abrir materiais reais por link, acompanhar o consumo e manter uma experiência coerente mesmo sem autenticação ou backend de produção.

Objetivos desta variante:

  • Preservar a interface do app real para preview e validação com stakeholders.
  • Exibir estados plausíveis para materiais, quiz e survey.
  • Evitar bloqueios por token expirado, API indisponível ou ausência de infraestrutura externa.
